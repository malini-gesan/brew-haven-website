# ☕ Brew Haven – Coffee Shop Website

Brew Haven is a responsive multi-page coffee shop website developed using HTML, CSS, and JavaScript. The website is designed to provide a visually appealing cafe experience with an interactive menu, shopping cart, checkout flow, gallery, and contact functionality.

## 📌 About the Project

The project represents a modern coffee shop website where users can explore Brew Haven, learn about the cafe, browse coffee and food items, view the cafe gallery, and interact with the online ordering interface.

The website follows a consistent cafe-themed design with responsive layouts and user-friendly navigation across all pages.

## ✨ Features

- Responsive multi-page website
- Home page with cafe introduction and navigation
- About Us section with:
  - Our Story
  - Mission
  - Vision
  - Why Choose Us
  - Cafe statistics
- Coffee and food menu
- Hot Coffee, Cold Coffee, Snacks & Desserts categories
- Menu search functionality

## 📄 Website Pages

### 🏠 Home
The home page introduces Brew Haven and provides navigation to the main sections of the website.

### ☕ Menu
The menu page displays different coffee, beverage, snack, and dessert options with their prices. Users can search for items and add them to the shopping cart. 

### 👩‍🍳 About Us
The About page presents Brew Haven's story, mission, vision, features, journey, and cafe experience. 

### 🖼️ Gallery
The gallery showcases different aspects of the Brew Haven cafe, including the interior, seating areas, coffee counter, and ambience. 

### 📞 Contact
The contact page provides the cafe's address, phone number, email, social media links, contact form, and opening hours. 

## 🛒 Ordering System

The menu includes an interactive shopping cart where users can:

1. Browse menu items
2. Search for a specific item
3. Add items to the cart
4. Increase or decrease quantity
5. Remove items
6. View the total price
7. Proceed to checkout
8. Enter customer details
9. Select a payment method
10. Confirm the order

The cart also uses browser local storage to retain cart information when the user refreshes or navigates away from the menu. 

## 🛠️ Technologies Used
